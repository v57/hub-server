## Linux Test Environment

Linux implementation and release checks use the Ubuntu amd64 machine reachable
over Tailscale as `v57u`. From the development Mac, connect with the configured
SSH alias:

```sh
ssh ubuntu
```

The Mac workspace at `/Users/v57/Documents/Hub` is the source of truth. Update
the Ubuntu copy at `/home/v57/Hub` with:

```sh
rsync -a --delete --exclude '.git/' /Users/v57/Documents/Hub/ ubuntu:~/Hub/
```

`--delete` removes files from the Ubuntu copy when they no longer exist in the
Mac workspace. Do not make unique edits only in the Ubuntu copy; either edit on
the Mac or rsync changed files back before the next source-to-target sync.

Run remote commands through a Bash login shell so `.profile` supplies the Go
and Bun paths:

```sh
ssh ubuntu 'bash -lc "cd ~/Hub && <command>"'
```

The machine boots with systemd and systemd-resolved, has passwordless sudo,
kernel WireGuard, network namespaces, nftables, conntrack, Podman, tcpdump,
tshark, Go, Node.js, npm, and Bun. Privileged acceptance tests may use
passwordless `sudo`. The Go modules select Go 1.25 automatically; the installed
toolchain is Go 1.26.5 on `linux/amd64`.
